# Deputatsverwaltung

SaaS zur Verwaltung der Deputatsstunden von Lehrkräften (Baden-Württemberg).

- Änderungen am Deputat schnell sichtbar machen
- Übersichtliche Auswertungen zum manuellen Abgleich mit **UNTIS** und **AS-DBW**
- Anbindung an das Stundenplanprogramm als Datenbasis

Vorgehen: Domain-Driven Design, Test-Driven Development.

> Datenschutz: Echte Personaldaten werden nicht ins Repository eingecheckt – nur Testdaten.
